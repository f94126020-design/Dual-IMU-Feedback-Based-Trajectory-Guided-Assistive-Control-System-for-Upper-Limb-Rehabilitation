# Dual-IMU-Feedback-Based-Trajectory-Guided-Assistive-Control-System-for-Upper-Limb-Rehabilitation
本專題定位為醫工應用下的嵌入式回授控制系統，而非完整自由活動式外骨骼。本系統以兩顆 IMU 量測上臂與前臂姿態，計算肘關節角度，並由系統產生復健目標角度或目標軌跡，讓使用者依照指定軌跡進行肘關節屈伸訓練。 控制核心採用目標軌跡追蹤與按需輔助控制。當使用者能自行跟上目標軌跡時，馬達降低輸出或不提供輔助；當使用者因肌力不足或疲勞而持續落後於目標軌跡時，PID 控制器根據追蹤誤差增加輔助輸出，協助完成指定復健動作。 本專題目前目標設定：完成雙 IMU 角度估測、目標軌跡產生、PID 閉迴路控制、簡易馬達致動展示，以及 RMSE、overshoot、settling time、phase lag 等控制性能分析。暫不把機器學習作為核心內容，避免分散控制主軸；機器學習與 EMG 可列為後續延伸。
